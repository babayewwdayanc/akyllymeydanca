# Akylly Meýdança — умное футбольное поле

Камера над полем снимает матч → AI находит игроков и мяч → игроки смотрят запись,
вырезают и отправляют свои моменты, видят пасы, ошибки, скорость, удары, MVP и свою
карточку игрока с рейтингом.

Идея похожа на турецкий Akıllı Saha, но код, дизайн и название — свои.
Интерфейс приложения — на туркменском языке. Документация для разработчиков — на русском.

## Что уже работает

| Для игрока | Для владельца поля |
|---|---|
| Регистрация: имя, фамилия, рост, вес, позиция, фото → сразу FC-карта (6 параметров + общий рейтинг). С фото автоматически удаляется фон, игрок «встаёт» на карту | Создать поле и матч, получить код матча для игроков |
| Открыть матч по коду, найти себя среди «Игрок 1…12» (без распознавания лиц) | Загрузить видео матча (с прогрессом) |
| Запись матча или 2D-схема по данным AI, лучшие моменты (голы, сейвы, сильные удары) | «Анализ AI» — в очередь для GPU-воркера, «Демо-анализ» — мгновенные тестовые данные |
| Вырезать клип и поделиться ссылкой (WhatsApp, Telegram, системное «Поделиться») | Исправить счёт вручную, удалить матч |
| Личная статистика: пасы (точные/все), ошибки, удары и их скорость, пробег, макс. скорость, спринты, отборы, тепловая карта | Калибровка камеры (JSON из `ai/calibrate.py`) |
| Оценка за матч 3–10, MVP по версии AI + голосование игроков | |
| Рейтинг игроков: общий, голы, MVP, скорость, удар, пробег | |
| Карточка пересчитывается по реальной игре, сохраняется как PNG | |
| (Необязательно) текстовый обзор матча от Claude | |

## Запуск

Нужен Node.js 22.13+ (база — встроенный SQLite, ставить ничего не нужно).

```bash
npm install
```

`npm install` сам скачает нейросеть для удаления фона (MODNet, ~26 МБ, лицензия Apache-2.0)
в `models/modnet.onnx`. Если сервер не может скачать её (нет доступа к huggingface.co),
скопируйте файл вручную или запустите `npm run models` позже. Без модели регистрация работает,
просто фото остаётся с фоном. Удаление фона идёт на сервере (~1–2 с на фото), телефону ничего
скачивать не нужно. На Linux и Mac M1+ используется быстрый `onnxruntime-node`, на остальных — WebAssembly.

```bash
npm start
```

Откройте http://localhost:3000. При первом запуске создаются демо-поле, 3 демо-матча (коды
`DEMO01`–`DEMO03`) и 8 вымышленных игроков — чтобы сразу было что посмотреть.
Панель поля: http://localhost:3000/#/admin, ключ по умолчанию `admin123`.

Переменные окружения:

| Переменная | Зачем |
|---|---|
| `PORT` | порт сервера (3000) |
| `ADMIN_KEY` | ключ панели поля — **обязательно поменяйте** в продакшене |
| `WORKER_KEY` | ключ AI-воркера (по умолчанию = `ADMIN_KEY`) |
| `DATA_DIR` | где хранить базу, фото и видео (`./data`) |
| `DEMO_MODE=0` | не создавать демо-данные |
| `ANTHROPIC_API_KEY` | включить текстовый обзор матча (Claude) |
| `CLAUDE_MODEL` | модель для обзора (по умолчанию `claude-opus-5-5`) |

Если на сервере установлен `ffmpeg`, клипы можно скачать как mp4. Без него клип — это
отрезок общего видео (открывается по ссылке и проигрывается по кругу).

Тесты: `npm test` (расчёт статистики на сервере + логика AI-событий на Python).

## Устройство

```
server/            Node.js + Express + SQLite
  index.js         все API-маршруты
  ingest.js        приём результата AI → статистика игроков
  rating.js        оценка 3–10, MVP, награды, карточка игрока
  demoAnalysis.js  симулятор матча (демо-данные в формате настоящего AI)
  summary.js       текстовый обзор матча (Claude, необязательно)
public/            интерфейс без фреймворков (работает на телефоне)
ai/                Python: компьютерное зрение
  analyze.py       видео → игроки, мяч, события → JSON
  events.py        пасы, потери, отборы, удары, голы, сейвы, физика
  calibrate.py     калибровка камеры (4 угла поля)
  worker.py        забирает матчи из очереди сервера
  SCHEMA.md        формат результата анализа
docs/AI-i-stoimost.md   как подключить AI и сколько это стоит
```

## Что сделать перед запуском для людей

- Поменять `ADMIN_KEY`, включить HTTPS (например, через Caddy или Nginx).
- Видео хранить в объектном хранилище (S3 / Cloudflare R2), а не на диске сервера.
- Вход по PIN — простой; для продакшена добавить SMS-код.
- Дообучить AI на видео со своей камеры (см. `docs/AI-i-stoimost.md`).
