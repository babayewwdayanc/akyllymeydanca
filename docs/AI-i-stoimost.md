# Как подключить AI к анализу матча и сколько это стоит

## 1. Какой AI нужен на самом деле

Пасы, ошибки, скорость мяча и пробег считает **компьютерное зрение** (детекция и трекинг объектов
на видео), а не чат-бот. Если отправить часовое видео в ChatGPT, Claude или Gemini, ответ будет
приблизительным: такие модели не умеют надёжно сосчитать 500 пасов и измерить скорость в км/ч.
Языковая модель пригодится в конце — написать по готовым цифрам обзор матча (это уже есть в
`server/summary.js`).

## 2. Как это работает

```
Камера над полем ──► видео mp4 ──► AI-воркер (компьютер с видеокартой)
                                   │ 1. YOLO: люди и мяч на каждом кадре
                                   │ 2. ByteTrack: «это тот же игрок, что кадр назад»
                                   │ 3. Калибровка: пиксели → метры поля
                                   │ 4. Цвет манишки → команда A / B (судья отбрасывается)
                                   │ 5. Владение мячом → пасы, потери, отборы, удары, голы
                                   ▼
                        JSON akylly-analysis/v1 ──► сервер приложения
                                                     │ точность пасов, ошибки, оценка 3–10,
                                                     │ MVP, награды, карточка игрока
                                                     ▼
                                                 телефон игрока
```

Как получаются цифры:

- **Пас**: мяч был у игрока A, потом у его партнёра B — точный пас A→B. Если мяч забрал соперник
  издалека — неточный пас плюс перехват. Если вплотную — отбор и потеря.
- **Ошибки**: неточные пасы плюс потери мяча.
- **Скорость мяча**: путь мяча в метрах за время между кадрами. При 25 кадрах в секунду шаг 0,04 с.
- **Удар**: мяч летит быстрее 45 км/ч в сторону чужих ворот. **Гол**: мяч пересёк линию ворот между штангами.
- **Пробег, макс. скорость, спринты**: по координатам игрока с поправкой на дрожание трекинга.
- **MVP**: самая высокая оценка за матч (голы, передачи, пасы, отборы, сейвы — плюс, потери — минус).

Всё это уже написано: `ai/analyze.py`, `ai/events.py`. Логика событий проверена тестом
`ai/test_events.py`. Настоящее видео через этот код ещё не прогонялось: нужна запись с вашей
камеры и видеокарта.

## 3. Пошаговое подключение

1. **Камера.** Повесьте её на высоте 6–8 м посередине длинной стороны, чтобы в кадр попадало всё
   поле. Нужны 4K (или хотя бы 1080p) и 25+ кадров в секунду. Мяч на записи — несколько пикселей,
   поэтому разрешение и резкость решают больше всего.
2. **Запись матча.** Камера пишет на регистратор или мини-ПК у поля. После матча файл загружается
   в «Панели поля» (кнопка «Загрузить видео») или автоматически скриптом.
3. **Калибровка — один раз.**
   ```bash
   python ai/calibrate.py --video match.mp4 --length 40 --width 20 --out calib.json
   ```
   Кликните 4 угла поля, затем вставьте JSON в «Панели поля» → «Новое поле».
4. **Компьютер с видеокартой** (у поля или в облаке):
   ```bash
   pip install -r ai/requirements.txt
   ```
   ```bash
   python ai/worker.py --server https://ваш-сервер --key ВАШ_WORKER_KEY --device 0
   ```
5. В «Панели поля» нажмите **«Анализ AI»**. Воркер скачает видео, проанализирует его
   и отправит результат. Матч станет «готово», игроки увидят статистику.
6. **Проверка без сервера**: прогоните `analyze.py` на одном видео и загрузите `out/analysis.json`
   через `POST /api/admin/matches/:id/result`.

### Как поднять точность (самое важное)

Стандартная модель `yolo11m.pt` обучена на обычных фото и плохо видит маленький мяч на
широком плане. Что делать:

- **Дообучить модель на своих кадрах.** Разметьте 1 000–3 000 кадров с вашей камеры
  (классы `player`, `goalkeeper`, `referee`, `ball`) в бесплатных CVAT или Roboflow. Затем
  дообучите: `yolo detect train data=field.yaml model=yolo11m.pt imgsz=1280 epochs=80`.
  `analyze.py` сам распознаёт эти названия классов.
- **Манишки с крупными номерами.** Тогда игрока можно опознавать по номеру (OCR) и
  обрывки треков склеиваются почти без ошибок. Без номеров игрок отмечает себя сам
  («Найти себя»), как в Akıllı Saha.
- **Две камеры** (по одной на половину поля) вместо одной: мяч крупнее, меньше перекрытий.
- **Счёт подтверждает администратор** (кнопка «Исправить счёт»): голы AI определяет хорошо,
  но не идеально.

Чего ждать честно: после дообучения на своём поле обычно получается 85–95% точности
по пасам и голам. Сложнее всего короткие касания в толкучке и высокие мячи: камера одна,
и высоту мяча она не видит.

## 4. Сколько это стоит

Цены ориентировочные, ноябрь 2026, в долларах США.

### Оборудование на одно поле (разово)

| Что | Цена |
|---|---|
| 4K IP-камера с широким углом (или 2 камеры) | $150–400 за штуку |
| Мачта/кронштейн 6–8 м + монтаж | $200–600 |
| PoE-коммутатор, кабели, ИБП, роутер | $100–200 |
| Запись у поля: мини-ПК или регистратор | $150–300 |
| **Итого на поле** | **≈ $700–2 000** |
| Вариант «анализ прямо у поля»: NVIDIA Jetson Orin Nano Super | $249 на старте продаж, по отчётам с июля 2026 — $399 |

Для сравнения, готовое решение Veo: камера $899 плюс подписка Team $1 299 в год (цены
промо-страницы для США). Но там будет их приложение и их бренд, а не ваш.

### Анализ одного матча (60 минут)

| Вариант | Как считали | Цена за матч |
|---|---|---|
| Облачная видеокарта RTX 4090 (RunPod, $0,34/ч) | ~45 000 кадров (каждый 2-й), ≈ 10–20 мин работы | **≈ $0,06–0,15** |
| Jetson у поля | работает ночью, только электричество | ≈ $0 (минус покупка Jetson) |
| Обзор матча текстом (Claude Opus 5.5) | ~3 000 токенов на вход и ~700 на выход | ≈ $0,03 (необязательно) |

Скорость обработки — оценка. Замерьте на своём видео: `--max-minutes 5` и время в логе.

### Хранение и сервер (в месяц)

| Что | Цена |
|---|---|
| Видео 1080p ≈ 1,8 ГБ за час (4K ≈ 6–7 ГБ) | Cloudflare R2: $0,015 за ГБ в месяц, скачивание бесплатно |
| Сервер приложения (VPS 2–4 ядра) | $10–40 |
| Домен + SSL | ≈ $1 (SSL бесплатно через Let's Encrypt) |

### Пример: 5 полей, по 6 матчей в день ≈ 900 матчей в месяц

| Статья | В месяц |
|---|---|
| Анализ в облаке (900 × ~$0,15) | ≈ $135 (или $0 с Jetson на каждом поле) |
| Хранение видео 30 дней (~1,6 ТБ) | ≈ $25 |
| Сервер | $20–40 |
| Обзоры Claude (необязательно) | ≈ $27 |
| **Итого** | **≈ $200–230 в месяц**, то есть ≈ $0,25 на матч |

Разово: оборудование 5 полей ≈ $3 500–10 000. Доработка AI под ваши поля (разметка
кадров, дообучение, настройка) — 2–4 месяца работы специалиста по компьютерному зрению.
На фрилансе в СНГ или Турции это примерно $1 500–4 000 в месяц, то есть $5 000–15 000 всего.
Разметку кадров можно сделать самим бесплатно или заказать за $300–1 500.

### Если запускаете в Туркменистане

Интернет там медленный и дорогой, часть зарубежных сервисов заблокирована. Поэтому:

- анализируйте видео **у поля** (Jetson или мини-ПК с видеокартой), а на сервер
  отправляйте только JSON со статистикой (≈ 1 МБ) и короткие клипы;
- сервер приложения держите в местном дата-центре — игрокам будет быстрее;
- облако (RunPod, R2, Claude) используйте только там, где оно доступно и стабильно.

## 5. Готовые сервисы вместо своего AI

Можно не делать своё компьютерное зрение, а взять готовое (Veo, Pixellot, Spiideo и др.).
Это быстрее на старте, но дороже в месяц и почти всегда с чужим брендом. Если выберете их, нужно
только переложить их данные в формат `ai/SCHEMA.md` — остальное приложение не меняется.
